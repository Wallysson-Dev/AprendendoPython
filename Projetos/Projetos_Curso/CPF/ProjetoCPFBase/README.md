# Projeto Base - Cálculo dos Dígitos Verificadores do CPF

Projeto desenvolvido para praticar lógica de programação, manipulação de listas e operadores condicionais.

---

## Objetivo
Treinar conceitos fundamentais da linguagem, como:
- Listas (`list`)
- Estrutura de repetição (`for`)
- Estruturas condicionais (`if / else`)
- Validação e manipulação de entradas do usuário
- Conversão entre `str` e `int`
- Formatação de strings com `join()` e `f-strings`

---

## Funcionalidades
- Receber os **9 primeiros números do CPF** do usuário
- Calcular o **1º dígito verificador**
- Calcular o **2º dígito verificador**
- Montar o CPF completo no formato `XXX.XXX.XXX-XX`
- Verificar se o CPF possui 11 dígitos e informar se é válido

---

## Aprendizados
- Aprendi a **limpar uma string** mantendo apenas números
- Entendi como funciona o **cálculo dos dígitos verificadores do CPF**
- Pratiquei o uso de **operadores condicionais inline**
- Transformei **listas em strings formatadas** usando `join()` e `f-strings`
- Reforcei conceitos de **loops e manipulação de índices em listas**

---

## Observações
- No início, houve repetição de código entre o cálculo do 1º e do 2º dígito
- Foi necessário pensar na **conversão correta de tipos** (`str` para `int` e vice-versa)
- O código funciona para CPFs com os 9 primeiros dígitos válidos

---

  - Comparar os dígitos calculados com um CPF completo para validação real
